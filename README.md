\# JobSearchWebsite



\## 1. Назва системи



NextStep — вебсайт для пошуку роботи.



\## 2. Призначення системи



Метою розроблення системи є створення вебсайту, який допоможе користувачам знаходити актуальні вакансії та роботодавцям розміщувати пропозиції роботи.



\## 3. Основна функціональність



Система передбачатиме реєстрацію та авторизацію користувачів, перегляд і пошук вакансій, фільтрацію пропозицій за різними критеріями, перегляд детальної інформації про вакансії та розміщення вакансій роботодавцями.



\## 4. Використані технології



\- Frontend: React, JavaScript, HTML, CSS.

\- Backend: Node.js, Express.

\- База даних: MySQL.

\- Система контролю версій: Git.

\- Платформа для зберігання репозиторію: GitHub.



\## 5. Структура проєкту



\- `docs/` — документація проєкту.

\- `src/` — вихідний код системи.

\- `tests/` — файли тестів.

\- `README.md` — опис проєкту та інструкція із запуску.

\- `.gitignore` — перелік файлів і папок, які Git не повинен відстежувати.



\## 6. Запуск проєкту



На поточному етапі проєкт містить початкову структуру та документацію. Для запуску вебсайту необхідно реалізувати клієнтську і серверну частини, налаштувати підключення до бази даних MySQL та встановити необхідні залежності.



Після налаштування середовища розроблення клієнтська і серверна частини запускатимуться окремо відповідно до їхніх конфігурацій.
